# 走遍俄罗斯 · 俄语词汇卡

一套**离线可用**的俄语背单词应用：图文卡片 + 情景例句 + 真人发音 + 四类题型练习 + 间隔重复复习 + 学习可视化。
词库按外研社《走遍俄罗斯》（引进版 *Дорога в Россию*）第 1 册的课序主题编排，交互与内容组织方式参考「百词斩」——**看图记词、情景例句、词汇与例句强关联**。

**一份代码，三个出口**：网页 / PWA（免安装）· Windows 桌面端（Electron）· Android 移动端（Capacitor）。

---

## 一、功能解读

### 1. 学习模式 · 按课分组 + 翻卡记忆

- 15 个单元卡片，每张显示进度环与待复习数量，点进去进入单词卡
- **卡片正面**：**该词专属实景配图**（一词一图，高清无水印）+ 俄语单词（印刷体）+ **俄语手写体对照** + 一键朗读；**卡片背面**：词性、汉语释义、俄文例句（**目标词自动高亮**，并给出变格/变位后的词形）+ 中文译文
- 卡片 / 列表双模式：列表模式一览整课词汇与掌握度，适合快速浏览
- 掌握度 6 档（生词 → 模糊 → 认识 → 熟悉 → 掌握 → 精通），可手动标记，也随答题自动更新

### 2. 练习模式 · 四类题型 + 即时反馈

| 题型 | 说明 |
| --- | --- |
| 看中文选俄文 | 中文释义 → 四个俄语选项 |
| 看俄文选中文 | 俄语单词 → 四个中文选项 |
| 拼写填空 | **点选字母块**组成单词（手机无需俄语键盘），自动避开多词短语 |
| 听音辨词 | 播发音选单词，可反复点击慢速重听 |

- 作答即反馈：正误高亮 + 该词释义、例句、朗读按钮；**答错自动进入生词本**
- 选择题作答前**不会**朗读答案（避免听觉泄题）；拼写题朗读作为听写辅助
- 练习范围可多选单元、题型可多选、题量 5–40，支持「只练生词本」

### 3. 复习机制 · 间隔重复

- 掌握度对应复习间隔：`0 / 10 分钟 / 1 小时 / 1 天 / 3 天 / 7 天`，精通后再答对延长到 15 天（SM-2 精简实现）
- 到期队列 + 自评三档：**忘了 / 模糊 / 清楚**，答「忘了」回到生词本
- **生词本**：错词自动收录，也可手动加入；手动加入的词只有手动才能移出；支持收藏页签与导出 CSV

### 4. 学习统计 · 可视化

- 7 个指标：今日接触词数、练习正确率、复习自评分布、连续学习天数、已学词数、生词本、待复习
- 4 张图表：近 14 天学习量（翻卡/复习/练习堆叠）、正确率趋势（含错题柱）、掌握度分布、各单元进度
- 统计口径分离：**练习正确率**只统计客观题，**复习自评**单独呈现，互不污染

### 5. 真人发音

- 346 条语音（173 单词 + 173 例句），微软 Edge 神经语音 `ru-RU-SvetlanaNeural`，**96kbps 高码率**（该引擎可用的最高音质档）
- 语速刻意放缓：单词 -5%、例句 -10%（标准、不催促），设置里还有 0.8 倍「慢速跟读」与「测试发音」自检
- 播放策略：安卓端走**原生音频**（最稳），网页/桌面用内置 MP3，失败自动重试后再回退系统 TTS
- PWA 模式可在设置页一键把全部语音缓存到本机，之后**完全离线**

## 二、使用提示

| 场景 | 操作 |
| --- | --- |
| 翻卡 | 点击卡片 / 空格；← → 切换单词；F 朗读 |
| 答题 | 键盘 1–4 选答案，Enter 下一题；听力题空格重听 |
| 复习自评 | 键盘 1/2/3 对应 忘了/模糊/清楚 |
| 手机端 | 底部标签栏切换五大模块；右上角齿轮进入设置（语速、慢速、离线语音、导出） |
| 首次使用建议 | ① 进「学习」按课浏览卡片 → ② 去「练习」用「今日推荐」检验 → ③ 每天先清空「复习」队列 |
| 数据备份 | 设置 → 导出学习记录（JSON）；生词本可导出 CSV |
| 安卓 App | 装好即用、全部内容离线；返回键：子页面 → 首页 → 再按退出 |

## 三、目录结构

```
russian-vocab/
├── index.html            # 应用外壳：侧边栏 / 顶栏 / 移动端底部标签栏 / 视图容器
├── styles.css            # 全部样式（浅色主题、响应式、动画、无障碍）
├── manifest.webmanifest  # PWA 清单（可安装到 Android / Windows / macOS）
├── sw.js                 # Service Worker：外壳预缓存 + 语音运行时缓存
├── js/
│   ├── data.js           # 编译产物：window.RV_DATA（15 单元 / 173 词）
│   ├── scenes.js         # 手写内联 SVG 情景插画（21 幅）
│   ├── store.js          # 状态层：localStorage 持久化 + 间隔重复调度
│   ├── audio.js          # 音频层：本地 MP3 优先，系统 TTS 兜底，离线语音缓存
│   └── app.js            # 路由、四大模块视图、练习引擎、图表渲染
├── assets/audio/         # 真人发音 words/ 与 sent/（各 173 条 MP3）+ manifest.json
├── icons/  build/        # PWA / Electron / Android 图标与启动图（脚本生成）
├── electron/main.js      # Windows 桌面端主进程
├── android/              # Capacitor 安卓原生工程
├── src/
│   ├── units.tsv         # 单元元数据（竖线分隔）
│   └── vocab.tsv         # 词条源数据（改这里即可扩词）
├── tools/                # 构建与测试脚本（见下表）
├── README.md             # 本文档
├── BUILD.md              # Windows / Android 打包指南（含国内镜像与排障）
└── AUDIT.md              # 产品审查报告（双视角 + 优化路线图）
```

`tools/` 一览：

| 脚本 | 作用 |
| --- | --- |
| `build_data.py` | `src/*.tsv` → `js/data.js`（支持第 8 列重音标注） |
| `gen_audio.py` | 批量生成俄语真人发音（断点续传，可换音色/语速） |
| `gen_icons.py` | Pillow 绘制 PWA / Electron / Android 全套图标与启动图 |
| `fetch_images.py` | 从 Bing 图片搜索抓取每个单词的专属配图（大图 + 知识共享许可过滤，自动排除带水印图库）；检索词在 `tools/img_prompts.tsv` |
| `build_web.py` | 构建 `dist/`（桌面端与安卓共用，增量写入） |
| `sync_android.py` | `dist/` → 安卓工程资产（`cap sync` 的稳妥替代，自带校验） |
| `pack_win.sh` | Windows 便携版 zip 打包 |
| `smoke.js` | 功能冒烟测试（jsdom，61 项断言） |
| `audit.js` | 产品审查（12 组场景，输出 P0/P1/P2） |

## 四、快速开始

**网页版**：直接双击 `index.html` 即可（零依赖、离线可跑）。也可用静态服务器托管以获得 PWA 安装能力：

```bash
cd dist && python -m http.server 8080
```

**Windows 桌面端**：运行安装包 `RuVocab-1.2.0-x64.exe`，或解压 `RuVocab-Portable-1.2.0.zip` 后双击 `RuVocab.exe`。

**Android**：安装 `走遍俄罗斯词汇卡-1.2-release.apk`（Android 5.1+，需允许安装未知来源应用）。

**从源码构建三端**：见 [BUILD.md](BUILD.md)。

```bash
npm install                                   # Electron / Capacitor 依赖
python tools/build_data.py                    # 编译词库
python tools/gen_audio.py                     # 生成语音（首次需联网）
python tools/gen_icons.py                     # 生成图标
python tools/fetch_images.py                  # 抓取每个单词的专属配图（首次约 6 分钟）
python tools/build_web.py                     # 产出 dist/

# 测试
NODE_PATH=<node_modules> node tools/smoke.js  # 61 项功能断言
NODE_PATH=<node_modules> node tools/audit.js  # 产品审查：期望 P0 0 · P1 0
```

修改词库：编辑 `src/vocab.tsv`（`单元|俄语|词性|中文|俄文例句|中文译文|配图键|重音词形`）→ `python tools/build_data.py` → `python tools/gen_audio.py`（只补新词）→ 在 `tools/img_prompts.tsv` 补一行新词的检索词 → `python tools/fetch_images.py`（只抓新词）→ `python tools/build_web.py`。

## 六、常见问题

**Q：发音没声音？**
先确认设备音量。网页/桌面版需浏览器允许音频播放（首次点击后才允许自动播放）；若内置音频缺失会自动回退系统语音，此时需系统装有俄语语音包。

**Q：手机上想完全离线？**
PWA：设置 → 离线语音 → 缓存全部语音（约 5MB）。安卓 App 安装包内已含全部语音，无需额外操作。

**Q：学习进度会同步到别的设备吗？**
目前进度保存在本机（localStorage / App 本地存储），可从设置页导出 JSON 备份。多端同步需要接入后端，见 AUDIT.md 路线图。

**Q：想加词、加课怎么办？**
编辑 `src/vocab.tsv` / `src/units.tsv` 后跑一遍上面的命令；新配图在 `js/scenes.js` 加一幅 SVG，并在 `js/app.js` 的 `SCENE_DESC` 补一句情景说明。

**Q：安卓 App 和网页版进度能互通吗？**
不能，两者存储独立。互相迁移请用「设置 → 导出学习记录」。
